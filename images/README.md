# Thư mục ảnh

Tải ảnh đại diện, ảnh ghi chú hoặc ảnh thành tựu của bạn vào thư mục này.

Để hiển thị ảnh thành tựu trên trang, thay khung `.image-placeholder` trong `index.html` bằng thẻ ảnh, ví dụ:

```html
<img src="images/ten-anh.jpg" alt="Mô tả ngắn về ảnh">
```

Sau khi tải ảnh lên GitHub, dùng đúng tên và phần mở rộng của tệp trong thuộc tính `src`.
