# Mẫu trang cá nhân

Trang giới thiệu sở thích và thành tựu cá nhân, thực hiện bằng HTML và CSS.

## Chỉnh sửa nội dung

1. Mở `index.html` và thay các phần trong dấu ngoặc vuông `[...]` bằng thông tin của bạn.
2. Có thể thêm ảnh vào thư mục `images/`. Thay khung `.image-placeholder` bằng thẻ `<img src="images/ten-anh.jpg" alt="Mô tả ảnh">` và chỉnh kích thước ảnh trong `style.css`.
3. Đổi màu, cỡ chữ, khoảng cách và đường viền trong `style.css`.

## Kiến thức sử dụng

- HTML: các thẻ cấu trúc trang như `header`, `nav`, `main`, `section`, `article`, `footer`, tiêu đề, đoạn văn và danh sách.
- CSS cơ bản: bộ chọn, màu sắc, cỡ chữ, khoảng cách, viền, căn chỉnh và Flexbox.
- Không dùng JavaScript hoặc backend. Trang là trang tĩnh; liên kết menu chỉ chuyển đến các mục trong cùng trang.
- Media query ở cuối `style.css` được dùng để sắp xếp nội dung trên màn hình nhỏ. Nếu lớp chưa học phần này, đây là phần tự tìm hiểu; có thể bỏ khối `@media` và giữ bố cục Flexbox.
- CSS Grid, hiệu ứng `transition`, bộ chọn `:focus-visible`, thuộc tính ARIA và kiểm tra form HTML không được dùng trong phiên bản này. Trang hiện không có biểu mẫu.

## Đưa lên GitHub Pages

Tải nội dung thư mục này lên repository GitHub. Trong **Settings → Pages**, chọn nhánh chứa `index.html` và thư mục gốc (`/(root)`). Sau khi GitHub Pages hoàn tất, trang sẽ được xuất bản.
