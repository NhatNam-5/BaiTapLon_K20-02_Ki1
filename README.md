# Mẫu trang cá nhân

## Chỉnh sửa
1. Mở `index.html`, thay nội dung nằm trong dấu ngoặc vuông bằng thông tin của bạn.
2. Thêm ảnh vào thư mục `images/`. Khi muốn hiển thị ảnh, thay khung `.image-placeholder` bằng thẻ `<img src="images/ten-anh.jpg" alt="Mô tả ảnh">`.
3. Tùy chỉnh màu sắc và bố cục trong `style.css`.

## Đưa lên GitHub Pages
Tải toàn bộ nội dung thư mục này lên repository GitHub. Trong **Settings → Pages**, chọn nhánh chứa `index.html` và thư mục gốc (`/(root)`). Sau khi GitHub Pages hoàn tất, trang sẽ được xuất bản.
